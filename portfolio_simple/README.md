# Madhura Bhuvad — Portfolio

A clean, responsive portfolio website built with plain HTML, CSS, and JavaScript. It has no build step, package installation, animation libraries, or external image dependencies.

## Run locally

1. Extract the ZIP file.
2. Open `index.html` in your browser, or open the folder in VS Code and use the Live Server extension.

## Publish on Vercel (free)

1. Create a new repository on GitHub and upload the contents of this folder (make sure `index.html` is at the repository root).
2. Sign in to [Vercel](https://vercel.com/) using your GitHub account.
3. Select **Add New → Project**, import the portfolio repository, and deploy.
4. Since this is a static HTML website, no framework or build command is required. Leave the framework preset as **Other** and the build command empty. The output directory can remain empty or be set to `.` if prompted.
5. Vercel will provide a free `vercel.app` URL.

## Files

- `index.html` — portfolio sections and project/contact links.
- `styles.css` — simple responsive styling.
- `script.js` — mobile navigation and current year.
- `assets/` — AI/ML and Data Science résumé PDFs.

## Project links

Live demos are linked for NutriVision-AI and Student Performance Predictor. Smart Outfit Recommender and Trackify link to their GitHub repositories and are identified as local projects without a live web demo.

## Before publishing

Check all repository and live demo links, confirm the résumé PDFs are the versions you want to share, and preview the page on desktop and mobile.
